# Pemrograman Dasar 🚀

Repository ini dibuat untuk menyimpan seluruh arsip pengerjaan modul mata kuliah **Pemrograman Dasar**. Di dalamnya terdapat latihan logika, implementasi sintaks, dan penyelesaian masalah sederhana menggunakan bahasa [Sebutkan bahasanya, misal: Python/C++/Java].

## 📂 Struktur Modul
* **Modul 1:** Pengenalan Lingkungan Pemrograman & Tipe Data
* **Modul 2:** Operator & Struktur Kontrol (Branching)
* **Modul 3:** Perulangan (Looping)
* **Modul 4:** Fungsi & Prosedur (Modular Programming)
